OpenThread is an open-source implementation of [Thread](https://www.threadgroup.org/), a low-power mesh networking protocol for connected home and commercial building products.

- Portable: an OS- and platform-agnostic core with a narrow platform abstraction layer.
- Small footprint: designed to run on resource-constrained microcontrollers.
- Flexible: build it as a full System-on-Chip, or as a co-processor (NCP/RCP) driven by a host.
